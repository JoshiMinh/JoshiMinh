# Joshi Minh Portfolio

Static HTML/CSS/JavaScript portfolio site.

## Structure

- `index.html` - portfolio landing page
- `assets/` - landing page CSS and JavaScript
- `games/*/index.html` - static game pages
- `games/*/` - each game's CSS, JavaScript, and image assets

## Run Locally

Open `index.html` directly, or serve the folder with any static file server.
