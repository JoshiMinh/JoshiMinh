❓ How to Play

🎮 Tools

  • 🏀 Ball - Click-drag to set launch direction and speed
  • 📏 Line - Click-drag to draw a wall segment
  • ⬜ Square - Click-drag to draw a rectangle
  • ⭕ Circle - Click-drag to set center and radius
  • 🔺 Triangle - Click three points to create a triangle
  • ✋ Move - Drag any item to reposition it
  • 🗑️ Delete - Click any item to remove it

⚡ Physics

Balls bounce off shapes and canvas edges with elastic collisions. Pause the simulation if things are moving too fast!
